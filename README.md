# VERDANT 23 Landing Page

빌드 과정 없이 바로 실행되는 정적 랜딩페이지입니다.

## 파일 구성

- `index.html` — 페이지 전체 마크업
- `styles.css` — 반응형 스타일
- `script.js` — CTA 스크롤과 구매 옵션 선택
- `assets/` — 상품 및 배경 이미지

`index.html`을 브라우저에서 열거나 GitHub Pages의 `main / root`를 선택하면 됩니다.
